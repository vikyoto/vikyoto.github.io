Análise de execuções n8n

React Supabase n8n Node.js
expand_more

target Problema

Necessidade de uma solução externa para análise e consulta das execuções do n8n, reduzindo o consumo de recursos e os gargalos causados pelo alto volume de execuções e dados armazenados na instância.

bolt Solução

Ao final de cada execução, um webhook é acionado para processar e armazenar um resumo dos dados relevantes no banco de dados, permitindo consultas e análises por meio de múltiplos filtros com uma visualização espelho do n8n.

trending_up Impacto

Eliminação de gargalos e travamentos na instância do n8n, com consulta de execuções sem restrições de tempo e redução de até 90% no armazenamento, preservando os dados relevantes.

API Negociação de Faturas

Javascript
expand_more

target Problema

Necessidade de integrar a IA a uma base de clientes inadimplentes para consultar faturas em aberto, calcular dias de atraso e gerar ofertas personalizadas em tempo real durante o atendimento.

bolt Solução

Desenvolvimento de uma bridge de integração com a base de dados e de uma API para consumo pela IA. A partir do CPF informado pelo cliente, a solução identifica contratos vinculados, consulta faturas em aberto, calcula o período de inadimplência e determina ofertas personalizadas. Os dados processados são disponibilizados à IA em tempo real para continuidade do atendimento.

trending_up Impacto

Identificação em tempo real da inadimplência do cliente, permitindo a geração e oferta automatizada de condições de negociação, sem necessidade de intervenção humana.
